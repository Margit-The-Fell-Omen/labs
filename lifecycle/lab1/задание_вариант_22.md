## Вариант 22

**Разработать утилиту «Сколько раз ты сказал „потом"».**

По введенному возрасту программа оценивает примерное количество раз, когда человек
откладывал дела на потом (используя усреднённую статистику).

На главной форме пусть будет кнопка «Ввести данные». По нажатию на нее пусть откроется
дополнительное окно для ввода информации. Последние введенные данные нужно запоминать в
главном окне и восстанавливать при повторном вводе. После этого на главной форме
отобразить результат – упомянутые величины. Если введены некорректные данные – показать
сообщение об ошибке.

Добавить каркас MVC с **активной** моделью. Неуспевающим студентам применить MVC с
пассивной моделью. Для совсем неуспевающих студентов – из паттерна MVC реализовать класс
контроллер, совмещенный с пассивной моделью.

## Цель работы

- изучить методы работы с одной из выбранных студентом сред разработки: IntelliJ IDEA
  (рекомендуемая среда), Eclipse, Microsoft Visual Studio Code, учитывая, что использовать
  можно только объектно-ориентированный язык программирования (C++, C#, Java, другой язык
  по согласованию с преподавателем);
- научиться разрабатывать в выбранной среде приложение с графическим интерфейсом;
- изучить MVC с активной и пассивной моделью.
